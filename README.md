# Patafeito App

Aplicativo mobile Expo/React Native do Patafeito.

## Executar

```bash
npm install
npm run start
```

Configure `EXPO_PUBLIC_API_URL` para apontar à API quando a integração for habilitada. A estrutura usa Expo Router, telas de onboarding e tabs para Início, Tarefas, Pet, Foco e Perfil. SQLite e a fila de sincronização possuem diretórios reservados para a implementação offline-first.
